A medida que avance el curso, los contenidos se irán agregando organizados por tipo de actividad:

| Carpeta        | Contenido                                   |
| -------------- | ------------------------------------------- |
| `examenes/`    | Exámenes teóricos y prácticos               |
| `tareas/`      | Tareas asignadas                            |
| `laboratorios/`| Laboratorios                                |
| `practicas/`   | Prácticas y ejercicios                      |
| `otros/`       | Otros entregables y evidencias del curso    |

> **Nota:** estas carpetas se crearán conforme se necesiten.
